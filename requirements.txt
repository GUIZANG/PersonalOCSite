# PersonalOCSite — environment & dependency requirements
#
# Runtime
# - Node.js >= 18 (LTS recommended)
# - npm >= 9
#
# Install project dependencies:
#   npm install
#
# Local development:
#   npm run dev
#   Open http://localhost:5173/Main/Main.html
#   Open http://localhost:5173/homePage/homepage.html
#
# Production build:
#   npm run build
#   npm run preview
#
# Notes:
# - This is a static multi-page Vite project with HTML entry files under public/.
# - Main archive scene uses Three.js from the project dependency/local static script path.
# - Local bundled static libraries are under public/libs/.
# - Shared static assets are under public/assets/images, public/assets/fonts, public/assets/audio.
# - Main archive cursor, hover particles, and scan-card VFX rely on bundled static scripts
#   plus the npm dependencies listed below.
# - If a dev server was already running before new public files were added, restart Vite
#   or use a fresh port so newly added static files are served.
